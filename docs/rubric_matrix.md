# Rubric Matrix for Demo Readiness

This document replaces percentage-readiness slides with a concise rubric mapping features to readiness levels and acceptance criteria.

Columns:
- Component
- Readiness: (Not started / Partial / Complete)
- Acceptance criteria
- Owner

Examples:
- CSV Analysis UI | Complete | Local explain fallback + deriveFactors + deep analyze merge working | Frontend
- Explain API | Partial | `/api/v1/decisions/{id}/explain_verbose` returns factors, DREAD, intel_hits | Backend

Use this file to drive demo prep checklists and to generate slide outputs for leadership.
