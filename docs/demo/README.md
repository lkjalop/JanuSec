# JanuSec — sample audit report (static demo)

[`index.html`](index.html) is a **self-contained, pre-rendered** ISO 19011 / 27035 / 27001
audit report generated by JanuSec from the VESPER *simulated* dataset. It needs no server,
no Ollama, and no build step — open the file and it renders.

It exists so the differentiator is visible in one click:

- **Grounded** — every actor, host and MITRE technique in the report is traceable to
  evidence; the platform structurally cannot emit a fabricated entity or ATT&CK id.
- **Custody-hashed evidence** — each finding carries a SHA-256 content hash, so a claim
  can be tied back to the immutable event behind it (ISO 19011 "objective evidence").
- **ISO-native** — one printable document combining the ISO 19011 audit report, the
  ISO/IEC 27035 incident records (root cause + lessons learned + breach-notification),
  and the ISO/IEC 27001:2022 corrective-action (CAPA) register.

> Synthetic data — `martin.chen`, `priya.nair`, `svc-backup` and all hosts are fictional.
> No real organisation.

## Sharing it as a link (GitHub Pages)

GitHub shows `.html` files as *source* in the repo browser, so to get a click-and-see link:

1. Repo **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
2. Branch **`main`**, folder **`/docs`**, Save.
3. The report is then live at `https://<user>.github.io/<repo>/demo/`.

## Regenerating

The file is reproducible and deterministic (fixed timestamps, no LLM):

```bash
python scripts/seed_grc_demo.py --static
```

For the interactive version (two-surface landing + drill-down), run the live demo:
`scripts/start_demo` seeds the same assessment and opens the browser.
