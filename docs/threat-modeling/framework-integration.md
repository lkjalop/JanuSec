# Threat Modeling & Framework Integration

JanuSec integrates multiple threat modeling frameworks to improve prioritization and scoring. Public guidance covers how frameworks are combined, not private scoring functions.

Frameworks referenced:
- MITRE ATT&CK mapping for TTP classification
- DREAD-inspired exploitability scoring (sanitized)
- Diamond model for actor-victim-phase representation

This combined approach yields more context-aware prioritization while remaining explainable.
