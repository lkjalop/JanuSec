# Changelog

## 2026-01-10 - Test stability and pipeline fixes
- Preserve API handler signatures and make ambiguous `kwargs`/`args` optional to avoid FastAPI autogenerated query-parameters causing 422s.
- Fix import-time issues (restored minimal `sitecustomize.py`, removed duplicate future-import in `asn_reputation.py`).
- DeepAnalyze pipeline: mark sessions `completed` quickly after steps finish, persist lightweight summary and spawn background finalizer for expensive LLM summarization to avoid test-time hangs.
- During tests the LLM default client now prefers `LocalDeterministicClient` to avoid external network calls (detects `PYTEST_CURRENT_TEST`, `TEST_HELPERS_ENABLED`, or `FAST_TEST_MODE`).

These changes improve test determinism and prevent external network calls during unit tests.
