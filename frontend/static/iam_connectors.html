IAM Connectors & Credentials

Provide real API credentials and webhook secrets for Okta, Azure AD, SailPoint, Active Directory, Ping, OneLogin and related IAM sources. Secrets are stored server-side under artifacts/config/iam_connectors.json and never echoed back—each card only reports whether a secret exists. After saving, restart the relevant connector workers or refresh the CSV multi-analyzer so HopGraph sessions can pull the telemetry in real time.

Deployment checklist

  • Configure real Okta / Azure credentials in environment variables (e.g. OKTA_API_TOKEN, AAD_CLIENT_SECRET) before toggling webhooks or pollers. The backend re-reads env on restart.
  • Wire tenant-specific headers/secrets for production webhooks. Use the generated callback URLs plus your tenant’s x-api-key so IAM events land in the right runtime partition.
  • HopGraph & the 21-stage pipeline automatically consume these connector events. Missing telemetry triggers the amber “Missing logs” indicator below.

Need additional connectors (e.g. Duo, CyberArk)? Drop the API keys here now and extend the CONNECTOR_DEFINITIONS helper later without changing the UI.
