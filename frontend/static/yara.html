YARA Rules Console

Optional feature, gated by YARA_ENABLED=1 and the yara-python package. This console helps you manage rules and test them against local samples.

1) Environment & Dependencies

  • Set YARA_ENABLED=1 in your environment to enable YARA scanning in the backend.
  • Install dependency: pip install yara-python in the server environment.
  • Configure a directory for local samples via YARA_SAMPLES_DIR (optional) for quick local scans.

2) Rule Management

Enter YARA rule text above and click Save. Rules are stored server-side when YARA is enabled (otherwise this is a local demo only).

4) Operational Notes

  • For safety, remote downloads from MalwareBazaar or other feeds are not performed automatically without explicit configuration.
  • When a sample is available, matched rules may emit factors like malware:yara_match_YourRule.
  • Large files are scanned with size/time limits to keep pipeline latency bounded.

5) YARA Health

Rule-level counters are exported to Prometheus metrics:

  • yara_rule_matches_total{rule=...}
  • yara_rule_bytes_scanned_total{rule=...}
  • yara_rule_timeouts_total{rule=...} and yara_rule_errors_total{rule=...} (if configured)

Open /metrics to inspect live counters. Consider scraping into Prometheus/Grafana for dashboards.
